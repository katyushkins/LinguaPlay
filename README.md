# 💜 LinguaPlay

### Изучение английского языка в игровом формате

LinguaPlay — настольное приложение для Windows, созданное на **C# и WPF**. Оно помогает изучать английский язык с помощью уроков, системы опыта и достижений.

## ✨ Возможности

- 📚 Интерактивные уроки английского языка
- 🏆 Система достижений
- ⭐ Получение опыта за обучение
- 📈 Отслеживание игрового прогресса
- 💾 Локальное сохранение прогресса на компьютере

## 💻 Установка

1. Откройте раздел [Releases](../../releases).
2. Скачайте архив `LinguaPlay_Setup_v1.1.zip`.
3. Распакуйте архив в отдельную папку.
4. Запустите `setup.exe` и следуйте инструкциям установщика.

## 🛠 Технологии

- C#
- WPF
- .NET Framework
